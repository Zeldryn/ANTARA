# Venus Full Exploration — Discovery Guide Copy Rewrite

## Scope

This pass changes **discovery / observation writing only**. The professional HUD, graphics-quality controls, region labels, altitude, distance, exit controls, terrain, material system, morphology, exit transition, and profile HUD remain unchanged.

## Voice target

Discovery moments now read like a friendly science guide: curious, short, direct, and understandable for children and teenagers without talking down to adults. Eyebrows rotate between phrases such as `TAHUKAH KAMU?`, `COBA PERHATIKAN!`, `LIHAT DEH!`, `TERNYATA...`, `UNIKNYA...`, and related prompts.

All 25 Venus observation cards were reviewed. The rewrite covers:

- card eyebrow / discovery hook
- title
- opening explanation
- short observation sections
- `KENAPA INI MENARIK?` explanation
- optional `Pelajari lebih lanjut` paragraphs
- nearby observation prompt wording

## Scientific guardrails

The rewrite does not change the underlying scientific claims or source links. Measurements, uncertainty language, distinction between radar brightness and elevation, and Magellan / NASA references are preserved. Uncertain interpretations continue to use wording such as `mungkin`, `masih diteliti`, or equivalent language.

## UI separation

Main interface labels remain professional. Labels such as `Kualitas`, `Wilayah`, `Ketinggian`, `Jarak fitur`, `Layar penuh`, and `Keluar dari Eksplorasi` were not converted into playful language.

## Result

The intended reaction is: **“Oh, jadi itu yang sedang gue lihat.”** The cards should no longer sound like a formal report or a robotic game notification.

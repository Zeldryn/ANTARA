The downloaded image is unchanged. The scene applies lighting, color management,
and subtle artistic bump shading in the renderer. That bump shading is derived
from texture brightness, not a scientific elevation model. The planetary map is
for visual illustration, not terrain measurement. Attribution is also visible
in the Mars scene.

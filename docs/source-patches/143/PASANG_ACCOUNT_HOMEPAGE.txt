ANTARA ACCOUNT HOMEPAGE HOTFIX
==============================

1. Copy semua isi ZIP ini ke C:\xampp\htdocs\
2. Pilih Replace files in the destination.
3. Tidak perlu import database ulang.
4. Tidak perlu menghapus akun yang sudah dibuat.
5. Buka http://localhost/ lalu Ctrl+F5 sekali jika tab lama masih terbuka.
